## ◈ Featured Projects

<details>
<summary><strong>🌾 Farm Fresh Network — Agri-Tech Digital Marketplace</strong></summary>
<br/>

A full-stack agricultural marketplace connecting farmers, buyers, logistics providers, and administrators through a single unified platform. Designed as a production-grade MERN system with geospatial querying, multi-role authorization, and real-time inventory management.

| Attribute | Details |
|:---|:---|
| **Stack** | React · Node.js · Express · MongoDB Atlas · TailwindCSS · JWT |
| **Architecture** | Multi-role SPA with protected routing per user type |
| **Scale** | 4 distinct user roles · 15+ RESTful API modules · Geospatial search |
| **Performance** | MongoDB geospatial indexing · Paginated catalog APIs |
| **Security** | SimpleJWT auth · Role-based access control · Input validation |
| **Impact** | Addresses last-mile agricultural supply chain inefficiencies in rural India |
| **Repository** | [github.com/sivasairuthvik/farm-fresh-network](https://github.com/sivasairuthvik/farm-fresh-network) |

The platform was built as a B.Tech final year capstone with real-world requirements sourced from agricultural supply chain research. Emphasis was placed on correct domain modeling — the four roles (Farmer, Buyer, Logistics, Admin) each carry distinct data flows and permission surfaces. The geospatial layer uses MongoDB's `$near` operator to surface produce listings within configurable radius, enabling hyperlocal discovery without third-party mapping costs.

</details>

| Attribute | Details |

Scene transitions are choreographed with GSAP timelines to maintain 60fps across the scroll journey. </details>

<details>
<summary><strong>🔗 LinkLeap — High-Performance URL Shortener</strong></summary>
<br/>

A production-deployed URL shortening service with analytics tracking, custom slug support, and a minimal API surface. Built for reliability and deployed to Vercel's edge network with zero cold-start latency on redirect paths.

| Attribute | Details |
|:---|:---|
| **Stack** | Node.js · Express · MongoDB · React · Vercel Edge |
| **Architecture** | Serverless API routes · Edge-optimised redirect logic |
| **Scale** | Custom vanity slugs · Click analytics · Expiry support |
| **Performance** | Sub-100ms redirect via Vercel Edge Network |
| **Security** | Rate limiting · URL sanitisation · Collision-safe slug generation |
| **Impact** | Developer utility with production deployment and real usage |
| **Repository** | [github.com/sivasairuthvik/link-leap](https://github.com/sivasairuthvik/link-leap) |

The core engineering challenge was ensuring redirect latency stays below perceptible thresholds regardless of origin geography. This was solved by deploying redirect logic as Vercel Edge Functions, colocating execution with the end user rather than a fixed origin region. Slug generation uses a base-62 encoding scheme with collision detection to guarantee uniqueness under concurrent write load.

</details>
